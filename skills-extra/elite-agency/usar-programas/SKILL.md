---
name: usar-programas
description: Controlar um programa do PC com o rato e o teclado, lendo os botões pelo nome
---
1. Abre o programa com abrir_app (ou abrir_url se for um site) e espera que a janela apareça.
2. Chama ver_elementos UMA vez para ler os botões, menus e campos pelo nome. Nunca adivinhes nomes.
3. Age passo a passo: clicar com o nome exacto, escrever_no_campo para campos, tecla para atalhos (enter, tab, ctrl+c...).
4. Depois de agir, chama ver_elementos para confirmar o resultado (o "Texto visível" mostra visores e mensagens).
5. Se um nome aparecer mais de uma vez, usa o indice pedido pelo erro.
6. Se falhares duas vezes no mesmo passo, pára e diz ao utilizador o que estás a ver.
7. Nunca uses alt+f4 nem fechar janelas sem o utilizador o pedir. O Esc do teclado pára tudo.
